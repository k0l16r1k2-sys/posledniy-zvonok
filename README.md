# Последний звонок — Online

После загрузки в Vercel задайте:
- NEXT_PUBLIC_SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY

`SUPABASE_SERVICE_ROLE_KEY` никогда не публикуйте и не вставляйте в код.

1. Выполните `supabase/schema.sql` в Supabase SQL Editor.
2. Загрузите файлы проекта в GitHub.
3. Импортируйте репозиторий в Vercel.
4. Добавьте две переменные окружения.
5. Deploy.
